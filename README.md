 Employee Workforce Distribution Dashboard

## Overview
This project is a dedicated **Business Intelligence and UI design showcase**, focusing heavily on visual hierarchy, custom styling, and clean proportional scaling rather than data extraction pipelines.
 
An interactive Tableau visualization analyzing the distribution of 5,000 employees across major industries and work locations (Remote, Hybrid, Onsite).

# Overview
This project features a high-impact treemap layout designed to provide an undeniable sense of scale and proportion. It allows stakeholders to instantly analyze headcount footprints and work-style preferences across the organization.

# Features
* True Geometric Scale:** Rectangle areas scale linearly with employee count totals.
* Work Location Grouping:** Clean macro-blocks breaking down remote flexibility versus traditional onsite setups.
* Unified Theme:** Distinct colour-coding mapped to work styles paired with crisp white grid borders for a polished presentation.
